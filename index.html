Firebase Setup Required
Ek baar setup karo, phir mobile/desktop dono pe kaam karega
Step 1: console.firebase.google.com pe jao
Step 2: "Add project" → project naam do → Continue
Step 3: Google Analytics → Disable → Create Project
Step 4: Left menu → Build → Realtime Database
Step 5: "Create Database" → Asia Southeast → Test mode → Enable
Step 6: Project Settings (⚙️) → General → "Add app" → Web (</>)
Step 7: App naam do → Register → firebaseConfig copy karo
✅ Step 8: Firebase config already set hai — kuch karne ki zaroorat nahi!
💡 Bilkul free hai — Firebase ka free plan (Spark) kafi hai is app ke liye.
⚡ Ek baar setup ke baad app normal kaam karega, ye popup nahi aayega.
